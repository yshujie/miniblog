## 实现结果

首页、主题总览、阅读外框、移动主题面板/目录抽屉、标题搜索、前后篇、加载与失败状态、404 已接入公开 API。统一品牌头部、基础样式与自然流页脚，移除两套无引用旧头部；浏览器标题、中文语言和头像图标同步更新。

新增 `/topics/:module`，章节定位使用 `?chapter=code`。顶部主题导航和首页主题入口进入总览；首页开始阅读、旧 `/blog/:module` 和文章深链接保持原协调器行为。普通页面导航置顶，章节入口由目录加载后定位，浏览器返回恢复历史位置。

文章仍使用原有安全 Notion 外链 iframe 和打开原文。API/DTO、目录 store、阅读加载协调器、阅读刷新生命周期与 URL 校验均未修改。有效阅读地址优先，文章 ID/地址变化才重建 iframe；十秒提示只提供原文建议。后台、Go 服务、数据库与同步流程没有改动。
