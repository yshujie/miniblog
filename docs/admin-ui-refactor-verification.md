## 交付范围

- 工作概览：真实同步状态、需核对事项、最近运行、最近有效目录；单项读取失败独立展示，缺失计数不填假零。
- 内容工作台：保留“Notion 自动同步”和“目录与收录”。同步为同一路由的概览、来源与绑定、页面状态、运行记录四个 tab，旧运行深链只读。
- 目录与文章库：目录树/窄屏选择器、当前目录资料与层级 CRUD、共享查询列表、按允许动作展示的菜单、外部链接连续收录及明确的重复处理。
- 文章资料：托管字段只读，只 PATCH 本地作者；手工资料保持发布状态；紧急下架、解除后待核验、草稿离开确认分别保留。
- 统一外壳：224px 导航、60px 顶栏、账户只读资料与退出、登录返回上下文、桌面与手机交互。780px 及以下导航/编辑面板适配手机，600px 及以下复杂列表使用卡片。

Notion / 飞书外部文档阅读不变；未增加正文编辑、全库来源过滤、批量命令、流量统计、账户编辑、改密、RBAC 管理、旧运行重试或网页历史接管。原 module / section / subsection / article/create 等兼容地址保留。读者应用与生产 Go 业务源码没有改动。

## 真实接口边界与已知限制

- 临时 MySQL 绑定 loopback 随机端口，内存数据挂载，无持久卷；只创建和清理带本次专用标签的容器。专用库名与空库保护拒绝复用现有数据库。
- 浏览器请求真实本机 Go HTTP，数据实际落入 MySQL；Notion HTTP 是本地替身，其他外发请求被阻断。不使用生产账号、生产数据库或真实 Notion token，报告不保存 JWT。
- `dry_run` 只读文章/目录；解除 hold 后公众接口仍 404；重新扫描当前来源的 `sync` 完成后变为 200。旧运行 ID 的读取不再次执行。
- 生产 `installRouters` 没有启动，因此此处通过不代表完整生产挂载、代理或生产安全验收。
- 表征测试确认现有后端问题：Authz 拒绝未中止后续 handler，Logout 不撤销已签发 JWT，MyInfo 返回固定 admin 角色。匿名创建/改密的路由注册位置仅静态发现，没有对生产探测。本轮仅修前端 logout JSON 请求与本地 token 清理，未修改这些后端问题。
- 真实 Notion 来源权限/iframe、生产接口与部署、Safari/iOS/Android 实机、作者业务使用验收均未执行，需单独记录，不能由本机 Chromium 或测试通过代替。
- 真实接口服务与专用 MySQL 已关闭并清理，专用容器剩余 0；其他 68 个容器的身份、状态、启动时间、重启次数和镜像一致。Notion 本地替身最终为 61 次请求、0 次写入；这些次数不是对真实 Notion 的访问。管理端演示应用与截图索引保留供审阅。
